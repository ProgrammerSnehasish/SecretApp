# Secret App
This is a practice Repository on Web Development Learning. It is a modern Web Development project built with [Vite](https://vitejs.dev/), [React](https://reactjs.org/), and [TypeScript](https://www.typescriptlang.rog/).

---

## Prerequisites:
### Nodejs and Npm(Node Package Manager)
You should need **Nodejs and Node Package Manager** for this project installed in your system. 
🔗[Download it from the official site.](https://nodejs.org/en/download). 
**Or installed via terminal:**

```bash
#for Linux(Debian or Ubuntu-based)
sudo apt update
sudo apt install -y curl
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs
#for macOS
brew install node
#to verify installation
node -v
npm -v
```
---
### Yarn
Then you should install Yarn. To install it in your machine, do the following.

```bash
npm install --global yarn
# or
npm install -g yarn
```
---
### Vite
After installaion of yarn, **if you want to fresh start with Vite**, then first make a folder(any) and then open the folder in terminal and do the following.

```bash
yarn create vite #If you want to create with yarn.
# or
npm create vite@latest #If you want to create with npm.
```
then you will be directed to a command line interface to create your project, select the needful and then enter into the project directory.

**Note: For this specific project, you don’t need to create a new Vite app(just need Nodejs, npm and yarn) — just clone and install dependencies.**

---
## 🚀 Project Setup
### Clone the repo

```bash
git clone https://github.com/ProgrammerSnehasish/SecretApp
cd SecretApp
```
**and then to get node modules and required packages(dependencies), enter in terminal**

```bash
yarn install
# or
npm install
```
**and then to start the development server, just enter**

```bash
yarn dev
# or
npm run dev
```
